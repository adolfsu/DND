🛰️ 联机远征

Online

由一位同伴担任「主持台」，其他人带着自己的角色卡加入同一场冒险。跨网络、跨设备，无需自建服务器。

🜂

我来主持

你的设备负责运行 AI 地下城主、保管剧情与先攻序列。创建之后把邀请链接发给同伴即可。

🎲

加入远征

输入同伴给你的房间码，带上你自己的角色卡进入同一张桌面。

它是怎么运作的

  1. 一人主持 —— 主持台的设备连接 AI 接口，负责全部叙事、裁定与先攻序列。
  2. 其他人加入 —— 各自用手机或电脑打开同一个网址，输入房间码即可进入。
  3. 各带各的角色卡 —— 每个人创建自己的冒险者，只有本人能修改自己的角色卡。
  4. 实时同步 —— 谁说了什么、掷出多少，全桌立刻看到；掉线重连后会自动补齐进度。

房间内容经房间码派生的密钥端到端加密；角色卡与存档仍然只保存在各自的设备上。

📖 地下城主手册 · 速查

Reference

第一章 · 属性与调整值

六大属性为力量 STR / 敏捷 DEX / 体质 CON / 智力 INT / 感知 WIS / 魅力 CHA。调整值 = ⌊(属性值 − 10) ÷ 2⌋。属性值 10–11 为 +0，12–13 为 +1，14–15 为 +2，16–17 为 +3，18–19 为 +4。

第二章 · 检定与熟练

任何有失败可能且失败有代价的行为，都通过 d20 + 属性调整值 (+ 熟练加值) ≥ DC 来裁定。熟练加值：1–4 级 +2，5–8 级 +3，9–12 级 +4，13–16 级 +5，17–20 级 +6。

难度DC典型情境
非常容易5注意到明显的响动
容易10攀爬一堵有落脚点的矮墙
中等15撬开一把好锁、辨识常见魔法
困难20在暴风雨中游泳、识破精湛的伪装
非常困难25徒手攀爬光滑的城墙
几乎不可能30说服一条古龙献出宝藏

第三章 · 优势与劣势

优势：掷两个 d20 取较高者。劣势：取较低者。二者同时存在则互相抵消，回到单骰。

第四章 · 战斗轮

  1. 先攻：所有人掷 d20 + 敏捷调整值，从高到低排序。
  2. 你的回合：可移动（通常 30 尺）+ 执行一个动作（攻击／施法／冲刺／闪避／协助／躲藏／预备／搜索／使用物品）+ 一个附赠动作（若有）+ 一个反应（每轮一次）。
  3. 攻击：d20 + 属性调整值 + 熟练加值 vs 目标 AC。命中后掷伤害骰。自然 20 为重击，伤害骰翻倍；自然 1 必定失手。
  4. 掩体：半身掩体 +2 AC，四分之三掩体 +5 AC。

第五章 · 休息

短休（1 小时）：可花费生命骰恢复 HP。 长休（8 小时）：恢复全部 HP 与法术位。

第六章 · 六大属性对应的检定

  • 力量：运动 — 攀爬、游泳、推挤、举重
  • 敏捷：体操、巧手、隐匿 — 平衡、脱身、开锁、潜行
  • 智力：奥秘、历史、调查、自然、宗教 — 记忆、推理、破译
  • 感知：驯兽、洞悉、医药、察觉、生存 — 观察、读心、追踪
  • 魅力：欺瞒、威吓、表演、说服 — 影响他人

第七章 · 桌面的骰子语法

语法说明
.r 2d6+3掷 2 枚 d6 再加 3
.r 1d20+5 攻击地精带备注的掷骰
.ra 察觉感知（察觉）检定，DM 会给 DC

.adv 隐匿 / .dis 隐匿优势 / 劣势检定

第八章 · 与 AI 地下城主相处

  • 描述你想做什么，而不是你想掷什么骰。「我想撬开箱子」优于「我要掷巧手」。
  • DM 抛出 [检定] 指令块时，点击它即可自动掷骰并回填结果。
  • 卡住时直接问：「周围有什么？」「他刚才说了什么？」DM 会补全场景。
  • 不喜欢某个走向，可以按「回溯」按钮，让 DM 重新叙述这一段。

第九章 · 关于数据

所有角色卡、存档、日志都保存在浏览器本地（localStorage）。清理站点数据会一并抹除。API 密钥同样只存在本地，不会上传到任何第三方服务器 —— 它只会被用于你填写的那个接口地址。

联机时，房间里交换的内容（发言、骰点、角色卡变更）会用房间码派生的密钥做 AES-GCM 端到端加密，再经过公共中转节点转发。中转节点只能看到一段密文，看不到内容；但请把它当作「房间号即暗号」—— 把邀请链接发给信任的人。

🔌 API 连接与服务

支持 OpenAI、DeepSeek、OpenRouter、硅基流动、月之暗面、智谱 及任意兼容接口。Key 仅存于本地浏览器。
